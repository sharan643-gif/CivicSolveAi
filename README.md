### Core Philosophy

> **Graceful Degradation** — Every feature works without internet, without Supabase, and without a Gemini API key. The app falls back to LocalStorage mock data automatically. Real Supabase and Gemini AI data simply enhances the experience when available.

```
    ┌────────────────────────────────────────────────────────────────┐
    │                    GRACEFUL DEGRADATION                         │
    │                                                                │
    │   Full Stack Mode          Fallback Mode                       │
    │   ───────────────          ──────────────                      │
    │   ✅ Supabase DB           ✅ LocalStorage                     │
    │   ✅ Gemini AI             ✅ Mock AI responses                │
    │   ✅ Auth + RBAC           ✅ Guest mode                       │
    │   ✅ Real-time             ✅ Static mock data                 │
    │                                                                │
    │   Both modes deliver the COMPLETE user experience.             │
    └────────────────────────────────────────────────────────────────┘
```

### 🎯 Civic Challenge Management

```
    ┌────────────────────────────────────────────────────────────────────┐
    │                    CHALLENGE LIFECYCLE                               │
    │                                                                    │
    │  📝 reported ──→ 🔍 under_review ──→ ✅ validated ──→ 📢 published │
    │                                                                │
    │  🤝 team_formation ──→ 💻 active_development ──→ 🧪 prototype    │
    │                                                                │
    │  🧪 pilot ──→ 🚀 implemented ──→ 🎉 resolved                     │
    │                                                                    │
    └────────────────────────────────────────────────────────────────────┘
```

- Submit challenges with title, category, district, description, severity, and attachments
- **AI auto-categorisation** — Gemini infers sector from description
- **Duplicate detection** — Semantic similarity prevents duplicate submissions
- **Priority scoring** — Auto-assigned on submission
- Full lifecycle: `reported → under_review → validated → team_formation → active_development → pilot → implemented → resolved`
- Upvote system, comment threads, SLA tracker per challenge
- **Challenge DNA card** — visual breakdown of root causes, affected population, budget estimate

## 4. 🚀 Quick Start

### Prerequisites
- **Node.js** 18+ (recommended: 20+)
- **npm** 9+ (or yarn/pnpm)
- **Git**

### Installation

```bash
# 1. Clone the repository
git clone <repo-url>
cd civiAi

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Edit .env with your keys (see Section 5)

# 4. (Optional) Set up Supabase database
# Run supabase_schema.sql in Supabase SQL Editor
# Then run seed_data.sql for sample data

# 5. Start development server
npm run dev
# → Opens at http://localhost:5180
```

```bash
npm run dev      # Start Vite dev server (hot reload)
```

## 20. 🧭 Navigation Architecture

### State-Based Routing (No React Router)

```javascript
// App.jsx — The routing system
const [currentRoute, setCurrentRoute] = useState('landing');
const [routeParams, setRouteParams] = useState({});

function handleNavigate(route, params = {}) {
  setCurrentRoute(route);
  setRouteParams(params);
  window.scrollTo(0, 0);
}

function renderPage() {
  switch (currentRoute) {
    case 'landing':
      return isMobile ? <MobileLandingPage /> : <LandingPage />;
    case 'explore':
      return <ExplorePage />;
    case 'submit':
      return <SubmitPage preFillData={preFillData} />;
    case 'detail':
      return <DetailPage challengeId={routeParams.id} />;
    // ... 33 more cases
  }
}
```

## 25. ⚡ Performance Notes

### Optimizations

- **Lazy loading** — Pages loaded on demand via state-based routing
- **Frame throttling** — Camera frames analysed max once per 2.5 seconds
- **Conversation history** — Only last 12 turns sent to Gemini (reduces token count)
- **Voice response tokens** — Capped at 350 for faster voice responses
- **15s timeout** — AbortController prevents hanging API calls
- **Mock data fallback** — No network calls for offline/cached data
- **CSS transitions** — GPU-accelerated transforms for animations
- **Image compression** — Evidence photos stored as base64 JPEG

### Bundle Size

```

├── index-[hash].js    ~1,372 KB (345 KB gzipped)
```
